# Part II · Explore

**Shaping, cleaning, transforming, and engineering features from raw data.**

The Explore stage is where raw data becomes analysis-ready. In practice, data scientists spend 60–80% of their time here — joining tables, handling missing values, engineering features, cleaning strings, creating derived variables, and reshaping data structures.

Heuristix provides 46 Explore nodes covering every common data transformation pattern. This part of the textbook explains each one — from simple column selection to advanced temporal feature engineering for machine learning.

## Why Data Preparation Matters

> "Garbage in, garbage out" — every model is only as good as the data fed into it.

Poor data preparation is the single biggest cause of model failure in production. Chapters in this part cover not just *how* to use each transformation, but *why* it matters and what goes wrong when it's skipped.

## Chapters in This Part

The 46 Explore nodes are organised by function:

**Joining & Reshaping** — Join, Stack, Multi Stack, Union, Append, Pivot, Explode, Collapse

**Filtering & Selection** — Filter Rows, Select Columns, Select Features, Drop Features, Sort, Deduplicate

**Feature Engineering** — Interaction, Ratio, Date Features, Window Features, Conditional Features, Bin Features, Trend Recipe, Shift, Performance Window, Observation Window, Event Target

**Cleaning & Imputation** — Fill Missing, Missing Imputation, Type Cast, Cleansing, Replace Values, Value Mapping, Padding, Fixed Value, Rename

**Advanced** — Formula, Aggregate, Summarize Data, Extract Substrings, Assign Unique ID, Clone, Split, Text Features, Analyze Sentiment, Generate Synthetic Data, Match Records, PySpark
